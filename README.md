## Research

**[TGIF: Multimodal Temporal Segmentation](https://github.com/shureduan/TGIF-Multimodal-Temporal-Segmentation)**
Multimodal (video + vibration) temporal action segmentation, where Dynamic Window Attention adapts the sensor window to the predicted action segment, sharpening attention-based fusion and improving segmentation accuracy.

**[Autonomous Delivery Robot System](https://github.com/shureduan/Autonomous_Delivery_Robot_System)**
A Unity-based multi-floor construction-site delivery robot system, connecting semantic topology, Theta* planning, capacity-constrained multi-trip scheduling, and Pure Pursuit execution, with a separate SAC study of local recovery.

**[F1TENTH: Human Prior Knowledge Defense Route Generation](https://github.com/shureduan/F1tenth_team11_final_project)**
Learns an offline per-segment defensive preference from track geometry and human racing priors, then executes it online as an explicit blocking objective inside a constrained NMPC controller.

**[Task-Aware Anchor-Delta Representations for Robot Learning](https://github.com/ailisilob/DELTA)** · *ongoing*
Task-aware anchor-delta representations for robot learning: sparse visual anchors plus task-relevant state deltas in place of dense video.
